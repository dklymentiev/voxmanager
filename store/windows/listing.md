# Windows, listing copy

> Draft. For a download page and/or Microsoft Store.

## Name
```
Vox Manager Server, Voice to PC
```

## Short description
```
Receive dictation from the Vox Manager phone app and type it into any window.
```

## Long description
```
The Vox Manager PC server lets your phone act as a microphone for your computer.
Run it, pair once with a 6-digit code, and the text you speak into the Vox Manager
app on your phone is typed straight into whatever window is active.

- Lives quietly in the system tray.
- Secure: one-time pairing, every message authenticated; it never types from an
  unpaired device.
- No account, no telemetry; your pairing key stays on your machine.

Requires the free Vox Manager app on your Android phone, on the same Wi-Fi network.
```

## System requirements
```
Windows 10/11. ~20 MB. No installation of Python required (standalone executable).
```
